## The placard

> Rubber stamp, wood and rubber, c. 1874. It pressed APPROVED ten thousand times, in the hand of a clerk who never read a word. Excavated from the mail room, ink still wet.

## Run

```sh
python3 main.py   # writes the placard to /output/entry.txt
```

`main.py` is deterministic: it writes the same single line on every run, with no network and no input. The line is 170 characters, inside the 180-character gate.
